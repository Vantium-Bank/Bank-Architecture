Section 11 Architecture Deep Dive

Enterprise Data Lakehouse & Databricks Data Engineering

Unified Lakehouse architecture bridging on-prem core banking and cloud digital channels for real-time analytics, regulatory reporting, and AI models.

Delta Lake Medallion
1. Bronze Layer (Landing Zone)

Raw Ingestion & CDC Stream

Continuous real-time change data capture (CDC) via Kafka Connect from on-prem Oracle 19c RAC (GoldenGate) and Cloud RDS PostgreSQL. Append-only immutable landing tables in Delta format on Cloud OBS.

2. Silver Layer (Conformed Data)

Customer 360 & Cleansed Ledger

Delta Live Tables (DLT) validate schema expectations, eliminate duplicates, and merge customer identifiers into a single golden truth record.

3. Gold Layer (Business Marts)

Prudential Returns & Executive Marts

Pre-aggregated dimensional models for CBN e-FASS/S4 returns, NDIC risk analytics, executive profitability dashboards, and MLflow feature stores for fraud detection.

High Availability & Disaster Recovery Matrix

Database Replicas, Backups & Tape Archival

Multi-tier resilience architecture safeguarding transactional ledgers across on-prem data centers and cloud platforms.

On-Premises Core Tier (Sections 4 & 5)

  • Infosys Finacle Database: 2-Node Oracle 19c RAC replicated synchronously via Active Data Guard (ADG) to Secondary Standby RAC in Abuja. Zero data loss (RPO = 0, RTO < 5m).
  • Dell EMC Data Domain DD6900: High-speed deduplication backup storage appliance. Ingests full database dumps daily and archive logs hourly with 30:1 deduplication.
  • Quantum Scalar i6 LTO-9 Tape Library: WORM immutable cartridges vaulted in climate-controlled off-site facility (CBN 7-year retention).

Huawei Cloud Tier (Section 2)

  • RDS PostgreSQL Multi-AZ: Multi-Availability-Zone synchronous hot standby replicas across AZ1, AZ2, and AZ3 with automated sub-30s failover.
  • Cloud Backup and Recovery (CBR): Automated hourly volume snapshots retained for 30 days and cross-region replicated.
